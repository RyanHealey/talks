## What's your favourite number of threads?

**Topics:** Multithreading · Clean code · Performance
**Format:** Lightning talk

It sounds like a silly question, and there's no single right answer. This talk runs through almost every possible answer, why each one is both right and wrong on a technical and a human level, and why a single thread can win on both performance and readability.

## The developers worked in two-by-two. Hurrah! Hurrah!

**Topics:** Pair programming · XP · AI coding agents

Pair programming isn't dead. This talk covers what makes pairing effective, why it so often fails, and how LMAX has kept it at the core of its development culture for over 15 years. It also asks whether pairing still pays off now that AI coding assistants are part of every developer's toolbox, and whether working with an AI assistant counts as pairing at all.

## Stop testing! (My patience)

**Topics:** Fast feedback · TDD · CI

Every time we write code, something tells us whether it worked, from the red squiggly line in the IDE to compile errors, test suites, and production monitoring. This talk is about why that feedback needs to be fast, what slow feedback costs in productivity and developer happiness, and how to speed it up across the whole development lifecycle.
